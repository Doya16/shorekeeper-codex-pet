守岸人 Codex 桌宠 · Windows 便携版 0.9.2

1. 在 Windows 10/11 x64 上安装并登录 Codex。
2. 完整解压 ZIP 到可写目录，双击 守岸人Codex桌宠启动.exe。
3. 右键 → 自动跟随当前任务。
4. 交互工作室：为每种动作设置 GIF、播放、气泡和语音。
5. GIF 素材 → 打开素材目录；放入 GIF/WebP/PNG/JPG/JPEG 后刷新并选择。
6. 语音支持 WAV/MP3/OGG/FLAC/M4A/AAC；字体支持 TTF/OTF/TTC。
7. 右键 → 调整大小，或 Ctrl + 滚轮实时缩放。
8. 外观、声音与迁移 → 保存与迁移，可保存、导入或导出全部配置和素材。

首次启动使用附带的默认配置。声音默认开启、音量 10%，可在声音页调整。
修改自动保存在 settings.json；GIF、字体、音频和默认配置随 ZIP 迁移。
再次迁移请导出 Windows 便携完整包，在新电脑完整解压后运行。
tools/创建桌面快捷方式.cmd 可创建桌面快捷方式。

从旧版升级：先在旧版导出“配置与素材 ZIP”备份；把新版解压到新目录，再从新版导入配置包。不要覆盖旧版目录。旧版配置包仍可导入。确认配置和声音正常后，再删除旧版或旧快捷方式。
程序模块在 shorekeeper_pet，辅助工具在 tools；启动时不需要移动其中的文件。
