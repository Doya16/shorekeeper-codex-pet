# v0.14.0 更新与恢复验证

验证环境：Windows x64，Python 3.12.14 / PySide6 6.11.2 / PyInstaller 6.22.3。全部操作使用隔离目录及测试配置，未修改运行中的个人桌宠或账号。

- 184 项 Python 测试通过。
- 实际打包 EXE：原有设置、表情、字体、音频解码、静音、锁定穿透、余额框隐藏、刷新反馈、启动联动等检查通过。
- 实际更新气泡：常驻、无声、两个按钮、语音优先后恢复、当天免提醒和检查频率控件通过；已逐张查看卡片与设置页截图。
- 真实旧版 0.13.3 → 0.14.0：独立 EXE 助手完成更新并自动启动，收到匹配版本、进程与随机标识的健康报告。
- 下载中断：在实际安装目录放入属于已退出进程的部分下载文件，下一次运行真正的启动器后已清理；活跃进程及无归属的目录不清理。
- 安装中断：构造未提交的安装日志及被改写的设置，实际启动器恢复原 EXE、原设置和旧版本，再次下载升级成功。不是物理断电试验。
- 新版无法启动：在隔离测试包中使用有效清单但不可运行的 EXE，实际助手捕获 Windows 启动错误，恢复并重新启动旧版。稳定启动器与个人设置未变化。
- GIF、音频、字体及默认素材共 254 个文件在升级、恢复、重试后 SHA-256 一致；个人设置逐字节一致。
- 配置素材包和完整便携包导入、导出、迁入含中文与空格的新目录，运行真实 EXE 通过。便携包包含当前程序版本，不含缓存与回退目录；全部导出文件逐一校验。
- 网络中断、清单/ZIP 校验错误、越界路径、个人文件覆盖、版本回退、磁盘不足及互斥安装的拒绝路径有专项测试。

完整包仍含三套 83 个 GIF、40 个默认音频、54 组语音字幕配对和两款字体。程序更新包不含个人设置、GIF、音频、字体或默认素材；包含完整程序运行库，不是二进制差分。

任务/余额逻辑沿用已验证功能。本轮更新验证使用离线界面、合成事件及隔离数据，没有发起新计费任务。签名、所有 Windows 安全软件、物理断电及所有网络环境不在本轮验证范围。
