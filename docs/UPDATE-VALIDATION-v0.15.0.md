# v0.15.0 陪伴功能

- 任务完成时飘字显示本轮用时，同时撒花；可选飘字字体、字号、描边、起点（默认桌宠内顶部居中）和拖动微调，也可以改成气泡或关闭。
- 贴边藏起：把桌宠拖到屏幕左右边缘松手，先靠边待机，安静到设定时间后换成探头动作藏起一半，露出一截墙，左侧自动镜像。有任务进行、有提醒、鼠标移上去或离开电脑 5 分钟以上时完整出来。旁边还有屏幕的那条边不会贴边。
- 全屏时隐藏：右键菜单“点击开启全屏时隐藏”，默认关闭。
- 每日小结：每天第一次打开时用气泡说说上一次的完成轮数、出错次数和最长一轮；右键“今日小结”随时查看。
- 喝水和久坐提醒：默认连续使用 60 分钟提醒一次，可选 30 分钟后再提醒、知道了或关闭提醒。
- 设置页改为分组卡片，“字体与大小”“桌面与声音”的每个板块旁有循环预览，锁定预览带模拟窗口；滚轮要先点选控件才会改数值；交互工作室可以向下滚动，素材列表更大。
