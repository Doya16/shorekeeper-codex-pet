# v0.15.1 飘字样式

- 飘字的计时可以设置加粗、斜体，并在调色盘中自定义颜色，“默认颜色”一键恢复；“完成播报”预览同步显示。
- 加粗不再依赖系统的假粗体：字体有粗体字形时使用粗体，没有时由程序加粗，边缘保持清晰。

## 验证

- 291 项 Python 测试通过，无窗口模式。覆盖样式选项的默认值和校验、加粗斜体和颜色在飘字上的实际像素、调色盘选择、取消和恢复默认、预览联动。
- 打包 EXE（源码提交 13d8ddd）：从公开 v0.15.0 经一键更新升级到 v0.15.1，GitHub 由本机代理模拟，校验真实签名；254 个素材文件哈希和个人设置不变。
- 加粗、斜体和自定义颜色的飘字样图在无窗口模式下渲染检查；默认窗口尺寸下所有设置页都没有左右滚动。

## 未覆盖

调色盘对话框只在无窗口模式下模拟选择，没有在真实桌面上手动操作。Codex 的完成事件来自本机会话记录，打包后的计时飘字没有用真实任务验证。中国大陆网络和各类安全软件未验证。

以上为项目自行验证的结果，不代表独立安全审计。
