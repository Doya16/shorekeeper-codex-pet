# Release validation

## v0.13.0 · 退出联动与更新来源

- 157 项自动化测试通过。涵盖最后实例退出、8 秒缓冲、托盘后台运行、短暂重启、残留辅助进程、权限错误、手动先打开桌宠，以及退出选项开关。
- 独立 EXE 使用隔离的 Windows 测试进程验证了真实进程创建和退出、有限查询权限检测及 Qt 退出信号。未关闭正在使用的真实客户端。
- 当前 Windows 普通权限账户已成功读取真实客户端的 PID、父 PID 与程序路径；无需提权，不读取进程内存。本次不新增常驻进程，复用桌宠已有后台线程，每 2 秒检查一次。
- GitHub 成功直连、超时／限流自动回退镜像、手动固定来源、拒绝外部下载链接、切换来源时丢弃旧请求结果、非阻塞 UI 均通过测试。
- GH-Proxy 公开版本接口及已发布文件读取成功。当前环境并非中国大陆网络，不能据此保证所有地区和运营商的连通性；设置保留手动切换。
- v0.12.0 覆盖升级与完整配置素材再次导出、移到新目录运行通过；镜像选择和关闭退出联动的个人设置保留，GIF、音频、字幕、字体保持完整。
