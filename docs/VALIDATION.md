# Release validation

## v0.12.0 · APP 小标与桌面快捷方式

- 142 项自动化测试通过：图标切换、非法配置兼容、保存与迁移、首次启动幂等、手动补建、移机标记与失败重试。
- 独立 Windows EXE 已验证纯净／APP 小标切换后的窗口和托盘图标一致；图标含 16、24、32、48、64、128、256 像素资源。
- 在独立临时目录实际创建 Unicode Windows 快捷方式，回读检查程序目标、工作目录和图标；删除后自动启动不重建，手动创建成功。
- v0.11.0 覆盖更新和便携包换目录启动通过，原有配置及素材保持不变。当前个人配置的 GIF、字体、语音、字幕经导入、再次导出完整包、移到新目录运行后保持；纯净图标选择保留。
- 原有锁定、鼠标穿透、额度刷新、静音、音频解码输出和字体检查继续通过。本轮未做新的在线对话联调。

## v0.11.0 · 锁定穿透与余额刷新

- 136 项自动化测试通过，覆盖锁定悬停透明度、锁按钮保留交互、余额点击刷新与拖边区分、菜单和配置迁移。
- 独立 EXE 检查通过：Windows layered/transparent 原生窗口标志可切换，锁定／解锁、余额刷新事件、透明度控件、静音、音频解码与输出及字体加载正常。
- 前一版本覆盖补丁后启动成功，253 项原有配置及素材文件受到保护。完整配置、GIF、音频、字幕与字体导入后可再次导出到新目录运行，锁定悬停透明度 85% 等设置保留。
- 余额点击测试不访问账户；本轮未进行新的在线任务联调。
- Codex 版锁定淡化后的实际点击穿透已人工确认可用。额度提示验证包括本地日期、小时／分钟倒计时、未知及过期刷新时间。
